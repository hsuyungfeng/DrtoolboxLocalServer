<objective>
Fix the dormant Chroma pipeline so it actually works: pass a real Chinese-aware embedding function into every Chroma collection call (D-01, D-02), point ingestion at the real document directories (D-03), and rename the Chroma collections to match the SQLite category names `general`/`special` everywhere that name appears in code (D-04). This is Stage 1 of the phase — it must land and be verified (`collection.count() > 0` for both collections) before Stage 2 (hybrid retrieval swap-in) can begin.

Purpose: Today `DocumentIngestor._init_chroma()` silently falls back to Chroma's bundled English-only embedding model, `config/ingest_config.json` points at document folders that were never populated, and Chroma collection names don't match the SQLite category names — so `data/rag/chroma/` has never actually been created. This plan makes the dense half of the future hybrid retriever real for the first time.
Output: A populated, Chinese-aware Chroma vector store for both `general` and `special` collections, with every collection-name/dir reference in the codebase updated in lockstep.
</objective>
